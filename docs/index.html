Clear boundaries

Questions technical teams ask.

Does this certify PCI DSS compliance?

No. Checkout Release Passport supports release-time evidence collection and change review. PCI applicability and compliance decisions remain with the merchant and its qualified assessor.

Does it replace Cloudflare, Jscrambler, Source Defense, or another runtime tool?

No. It is a release-control artifact inside GitHub Actions and can complement continuous client-side monitoring.

Why is this different from a Git diff?

A Git diff describes source changes. The passport records browser-observed script fingerprints, selected headers, baseline comparison, approval status, and workflow provenance for an authorized checkout.

Will you receive payment or customer data?

No form submission is required, and the evidence format intentionally excludes cardholder data, credentials, cookies, form values, query values, response bodies, and complete script bodies.
